# 保育士カレンダー アプリリダイレクトページ

iOSとAndroidの統一URLです。

このページにアクセスすると、訪問者のデバイスに応じて自動的にAppStoreまたはGoogle Playにリダイレクトされます。

## 使用方法

以下のURLを記事やSNSに貼り付けてください：

```
https://kazutoshi-yoshizawa.github.io/shift-app-redirect/
```

- **iPhone/iPad**: App Storeにリダイレクト
- **Android**: Google Playにリダイレクト
- **PC等**: App Storeにリダイレクト
